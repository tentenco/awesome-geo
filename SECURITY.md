# Security policy

This repository is primarily documentation, but links, workflows, and any future scripts can still create security risks.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository:

<https://github.com/tentenco/awesome-geo/security/advisories/new>

Do not open a public issue for an unpatched vulnerability, malicious link, leaked secret, or private personal information. Include the affected file or workflow, impact, reproduction details, and a suggested mitigation if available.

For ordinary broken links, inaccurate resources, or public spam reports, use a normal issue.

## Supported version

Only the current default branch is maintained. Because the project is a living collection, older commits and linked third-party resources are not supported snapshots.

## Scope

Relevant reports include malicious or compromised listed URLs, workflow injection, unsafe action configuration, exposed credentials, dependency compromise, and content that puts contributor privacy at risk. Product vulnerabilities in a linked third-party tool should be reported to that vendor unless this repository creates additional exposure.
